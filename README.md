# Aquagate Portal – Landing Page Wahana Wisata Kolam Renang

Aquagate Portal adalah landing page berbasis SPA untuk wahana wisata kolam renang.
Halaman ini menampilkan informasi paket tiket, fasilitas, jadwal kunjungan, dan
promo yang dapat dikelola melalui backend terpisah.

## Teknologi yang Digunakan

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Menjalankan Proyek Secara Lokal

Pastikan Node.js dan npm sudah terpasang di komputer.

```sh
# Install dependensi
npm install

# Menjalankan server development
npm run dev
```

Secara default, Vite akan berjalan di `http://localhost:5173` (atau port lain
yang ditampilkan di terminal).

## Script npm

Beberapa script yang tersedia:

- `npm run dev` – Menjalankan server development Vite.
- `npm run build` – Build aplikasi untuk produksi.
- `npm run build:dev` – Build aplikasi dengan mode development.
- `npm run preview` – Menjalankan preview hasil build.
